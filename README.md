# 사자연성 공개 실행본

이 폴더는 사자연성의 정적 실행 파일만 담은 깨끗한 GitHub Pages 배포본입니다.
개발 저장소의 과거 커밋, 로컬 출력물, 생성 원본, 비공개 메타데이터를 포함하지 않습니다.

- 게임 시작 파일: `site/index.html`
- 배포: `.github/workflows/deploy-pages.yml`
- 라이선스와 출처: `site/THIRD_PARTY_NOTICES.md`, `site/docs/submission/ASSET_AND_LICENSE_MANIFEST.md`

새 공개 저장소의 첫 커밋으로만 사용하고, 기존 개발 저장소의 Git 이력을 병합하거나 미러링하지 마십시오.
