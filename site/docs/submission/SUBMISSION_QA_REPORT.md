## 실제 브라우저 검증

- 3막 15노드 전체 경로를 디버그 가속으로 완주하고 최종 보스 `심해월 자령왕` 뒤 `RUN COMPLETE · 연성 완료` 결과를 확인했습니다.
- 완주 경로는 전투 11회를 포함했으며 전투→보상→다음 노드→최종 결과 사이 소프트락과 콘솔 오류가 없었습니다.
- 전투 저장 뒤 새로고침·재개 시 같은 적, 체력, 턴, 노드가 복원됐습니다.
- 게임오버 저장 단계가 `부활 판정 대기`로 보존됐습니다. 빈 캔버스와 부분 획은 제출해도 실패했고, 충분한 획은 제출 버튼을 누른 뒤에만 부활했습니다.
- 부활 뒤 체력 30%, 보호막 12, 부활 사용 완료 상태가 새로고침 뒤에도 유지됐습니다.
- 키보드로 타일 선택·상하좌우·대각선 이동·놓기를 완료했고 모달 Tab 순환과 Escape 닫기를 확인했습니다.
- 팡팡 모드는 별도 HUD와 기존 교환 규칙을 유지했으며 로그라이크 변경이 해당 로직을 수정하지 않았습니다.
- 유물 18종과 이벤트 12종의 43개 효과 유형을 정적 목록이 아니라 실제 전투·보상 훅까지 대조했습니다. 기본 큐 14칸, 유물 확장 저장 18칸, 팡팡 큐 12칸을 분리 검증했습니다.
- 800개 경로 시드에서 이벤트 12종과 조우 15종의 도달성을 검사해, 기존에 경로에 없던 1막 정예 조우를 발견·연결했습니다.
- 학자의 등불 보상은 유물 풀이 소진된 경계 상태에서도 일반 3장+미리보기 1장으로 유지됐습니다. 1280×720에서는 4열, 390×844에서는 2×2로 표시되며 페이지 스크롤과 잘림이 없었습니다.
- 로그라이크 전용 `유물 18종 지급 · 효과 QA` 버튼을 추가해 모든 유물 훅을 재현 가능하게 했고, 모바일 디버그 패널도 2열로 전체 버튼과 닫기 동작이 한 화면에 들어오는 것을 확인했습니다.
